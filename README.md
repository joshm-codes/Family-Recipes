# Family Recipes Website:

    A simple multi-page recipe website built while learning HTML and CSS.

## About:

This project was created as part of my early Front-end development learning journey. The website contains several recipe categories and demonstrates foundational HTML and CSS concepts including:

- Multi-page website structure
- Navigation between pages
- Images and media organization
- External stylesheet linking
- Lists and content formatting
- Basic page layout and styling
- File and folder organization

One goal of this project was to practice writing and organizing code manually. This entire site was originally written in Notepad while learning the fundamentals of web development before moving to a more advanced development environment.

## Features:

- Home page with recipe categories
- Appetizers
- Main Dishes
- Side Dishes
- Soups and Salads
- Desserts
- Shared styling across all pages
- Organized CSS and image assets


## Technologies Used:

- HTML5
- CSS3

## What I Learned:

Through this project I gained experience with:

- Creating and linking multiple HTML pages 
- Organizing project files and folders 
- Working with relative file paths 
- Linking external CSS stylesheets 
- Managing image assets 
- Troubleshooting broken file references
